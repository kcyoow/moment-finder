# 할 일: 뽑힌 후보가 요청에 맞는지 확인하기

사용자가 영상에서 찾고 싶은 장면을 한 줄로 적었다. 다른 모델이 그 영상 전체를 1초씩 보고 후보 구간을 몇 개 골랐다. 그 모델은 자주 헛짚는다. 비슷해 보이는 다른 장면을 고르기도 하고, 찾는 장면이 영상에 아예 없는데도 무언가를 고른다.

후보마다 프레임 8장을 준다.

- (A) 그 모델이 가장 확신한 1초의 연속 4장 (0.5초 간격, 시간 순서)
- (B) 그 구간 전체에서 고르게 뽑은 4장 (시간 순서)

후보마다 판단한다: **이 구간에 사용자가 찾는 장면이 실제로 담겨 있는가.**

## 지킬 것

- 프레임에 보이는 것만으로 판단한다. 보이지 않는 것을 짐작으로 채우지 않는다
- 비슷해 보이지만 다른 것은 맞는 것으로 치지 않는다. 무엇이 어떻게 다른지 구별해서 본다
- 요청이 막연하면(예: "하이라이트") 그 종류의 영상을 보는 사람이 하이라이트로 여길 장면인지로 판단한다
- 찾는 장면이 영상에 아예 없을 수 있다. 그러면 모든 후보의 확률이 낮아도 된다. 억지로 하나를 고르지 않는다
- 후보끼리 견주지 않는다. 후보 하나하나를 따로 판단한다

## 내놓을 것

JSON 하나만 낸다. 다른 글은 쓰지 않는다.

```json
{
  "candidates": [
    {"id": 1, "see": "<프레임에 보이는 것, 한 문장>", "p": 0.0}
  ],
  "note": "<전체에 대해 한 문장>"
}
```

- `candidates`에는 받은 후보를 모두, 받은 순서대로 넣는다
- `p`는 0과 1 사이의 수다: 이 구간에 사용자가 찾는 장면이 담겨 있을 확률
